This introduction does not establish package compatibility, API signatures, licensing terms, or deployment requirements.

NativePHP Desktop combines PHP access to operating system capabilities, application build and packaging tools, and a bundled PHP runtime. Desktop builds on Laravel. The introduction leaves the UI toolset to the application.

Planning application: identify the required desktop capability and existing installed version before choosing an integration. A desktop target alone does not justify a new domain abstraction.
