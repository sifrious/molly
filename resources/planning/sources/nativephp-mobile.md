NativePHP Mobile runs a Laravel application on the device through a bundled PHP runtime and Swift/Kotlin bridges. The v4 introduction describes EDGE Blade components that render native views. The application ships with each installation and can operate offline.

Planning application: name the required mobile capability, supported platform, and offline data behavior. Verify the installed major version before choosing an API. Mobile and Desktop are separate documentation tracks.
