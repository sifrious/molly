Persisted evidence

Bound, execute, verify, inspect, accept

A passing test supports a claim. It does not prove the entire application is correct. Molly never commits for you.

  1. Bound

    Name the task, the files it may touch, and the Pest test that must pass.

  2. Execute

    The agent proposes a change. Molly applies only allowed-file edits.

  3. Verify

    Pest runs the required test. Tarpit reviews complexity. Clever records measurements on the side.

  4. Inspect

    Attempts and receipts stay on disk. Bounded retries keep the earlier evidence.

  5. Accept

    A person reads the diff, runs the wider suite, and decides whether to integrate.

Why Molly

Molly is named for Molly Bloom, from James Joyce’s Ulysses. Her chapter, “Penelope”, opens with yes and closes with one of the most famous yeses in literature.

yes I said yes I will Yes.James Joyce, Ulysses, 1922

For the chapter and its adaptations, see Nick Bentley and James Peacock, “Stories into song: theory and co-creative practice of adapting literary fiction into pop and rock songs”, Adaptation, Oxford Academic, 2024.

Software is full of yes. Yes, we can build it. Yes, the model can change the file. Yes, the abstraction can be added. Molly’s yes has to be earned.

Molly with Bloom

Bloom owns the worktree, branch, diff, agent session and pull request flow. Molly exports a task contract for that workspace and keeps the tests, attempts, receipts and approval state.

Bloom QuickStart

Molly never creates a second Bloom worktree.

Generation is cheap. Judgment isn’t.

Complexity is adjacent to correctness.

planning principle

Prioritize

Doing the wrong thing efficiently is still doing the wrong thing. Ask what should happen next, what is blocking progress, the smallest verifiable slice, and what can be left out.

architecture principle

Seams

Use the seam the framework already gives you: events, contracts, middleware, bindings, drivers, commands, policies, jobs and configuration.

blocking gate

Tarpit

A complexity review, separate from Pest, that can keep a task incomplete. Not a quality score. A model cannot override it.

advisory measurement

Clever

Before and after measurements recorded next to the run. Never one score, never a verdict. clever.mary.win

Cleverness Is A Loan

At Laracon US 2026, Mary Perry argued that every abstraction, novel mechanism or architectural trick is a loan someone has to service later. Molly applies that talk: as generation gets cheaper, restraint and verification matter more.

Watch the talk on YouTube · clever.mary.win

Local first, on purpose

Ollama is first-class

The QuickStart talks to Ollama on loopback with no paid account.

No silent fallback

If local Ollama fails, Molly stops and says why. Hosted providers are explicit settings.

Sandbox when the host allows it

Molly uses stronger process isolation when the host supports the required Linux sandbox features. molly:doctor reports whether that safe workflow is available.

Knowledge is advisory

Queues, routing, testing, validation, the container, Eloquent and events. NativePHP and Tarpit notes live in their own namespaces. Knowledge cannot widen files, touch a protected test, or declare a task complete.

What ships today, and what does not

Ships today
  • Bounded Laravel coding tasks
  • Protected acceptance tests
  • Pest with false-green protection
  • Required Tarpit review
  • Separate Clever measurements
  • Bounded retries and history
  • Local Ollama, explicit Amp
  • Local MCP tools and web UI
  • Project and Laravel knowledge graphs
  • NativePHP knowledge
  • Decisions, journals, snapshots
  • Optional component previews

Not yet

Verified Orb identity. Remote execution selection. Molly opening or merging pull requests itself. A compiled Bloom macOS integration. Visual previews inside Bloom. Laravel knowledge beyond the areas listed above.

Humans still make the final integration decision.

Install the current release

PHP 8.3 or later, Laravel 12 or 13, Pest, Git and a working database. Molly installs from the public GitHub repository until it is listed on Packagist.
